Coasio is a high-performance **C++23 coroutine runtime** built on top of [standalone Asio](https://think-async.com/Asio/). It separates asynchronous I/O event polling from coroutine task execution, pairing Asio's network and timer drivers with a dedicated multi-threaded work-stealing scheduler.

---

## Why Coasio?

Traditional asynchronous C++ programming with callback-based Asio often leads to fragmented logic, complex lifetime management, and tangled error handling. While C++20 introduced language-level coroutines (`co_await`, `co_yield`, `co_return`), the standard library does not provide a coroutine runtime or an off-the-shelf task type.

Coasio bridges this gap by providing:

1. **First-class Coroutine Primitives:** Move-only `coasio::task<T>` with symmetric transfer for zero-overhead coroutine chaining.
2. **Dedicated Coroutine Scheduler:** Coroutine suspensions and resumptions run on a pool of worker threads with round-robin work-stealing queues, decoupled from the I/O event loop.
3. **Structured Asynchronous I/O:** High-level wrappers for TCP, UDP, timers, and filesystem streams that return `std::expected<T, std::error_code>` and integrate seamlessly with `co_await`.
4. **Cooperative Cancellation Trees:** Hierarchical cancellation scopes that automatically propagate through parent-child task hierarchies and trigger Asio cancellation slots.
5. **Safe Blocking Offload:** A built-in thread pool for offloading synchronous file system calls or third-party blocking routines via `coasio::spawn_blocking`.
