# Runtime Internals Overview

This section documents the internal implementation, concurrency algorithms, and design choices of Coasio.

:::note
The pages in this section describe **internal implementation choices** that help contributors and maintainers understand how the library works. These are separate from the user-facing contracts and guarantees promised in the [Core Concepts](file:///C:/dev/cpp/coasio/docs/src/content/docs/concepts/tasks.mdx) and [Reference](file:///C:/dev/cpp/coasio/docs/src/content/docs/reference/index.mdx) sections.
:::

---

## Subsystem Architecture

```text
                               +-----------------------------+
                               |     Application Coroutine   |
                               +-----------------------------+
                                              |
                          co_await / spawn / spawn_blocking
                                              |
        +-------------------------------------+-------------------------------------+
        |                                     |                                     |
        v                                     v                                     v
+-----------------------+           +-----------------------+           +-----------------------+
|   Coroutine Runtime   |           |    Asio Event Loop    |           |     Blocking Pool     |
|   & Work Stealer      |           | (io_context + Driver) |           |   (Dedicated Pool)    |
+-----------------------+           +-----------------------+           +-----------------------+
| * Per-worker queues   |           | * IOCP / epoll driver |           | * std::condition_var  |
| * 256-slot ring buf   |           | * Sockets, Timers     |           | * Task queue & worker |
| * Global FIFO fallback|           | * Cancellation slots  |           |   thread join         |
| * Half-queue stealing |           | * Single/Multi thread |           | * Enqueue cancellation|
+-----------------------+           +-----------------------+           +-----------------------+
```
