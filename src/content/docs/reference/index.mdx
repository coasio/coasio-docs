## 2. Runtime Configuration (`runtime_builder`)

The [`coasio::runtime_builder`](https://github.com/coasio/coasio/blob/main/include/coasio/runtime.hpp#L395) class configures and instantiates the runtime:

```cpp
#include <coasio.hpp>

coasio::runtime rt = coasio::runtime_builder{}
    .set_worker_count(8)           // Number of coroutine worker threads
    .set_io_worker_count(2)        // Number of dedicated Asio I/O threads
    .set_blocking_pool_size(4)     // Size of the background blocking pool
    .build();
```

### Configuration Options

| Builder Method | Default Value | Description |
| :--- | :--- | :--- |
| `set_worker_count(size_t)` | `std::thread::hardware_concurrency()` (min 1) | The number of OS threads running coroutines via the work-stealing scheduler. |
| `set_io_worker_count(size_t)` | `1` | The number of threads executing Asio's `io_context::run()` for socket and timer events. |
| `set_blocking_pool_size(size_t)` | `1` | The thread pool capacity dedicated to `spawn_blocking` and filesystem operations. |

## 3. Header Organization

Coasio is designed as a modular library with clean top-level and subsystem headers:

* [`<coasio.hpp>`](https://github.com/coasio/coasio/blob/main/include/coasio.hpp) — Umbrella header including core types (`task<T>`, `runtime`, `spawn`, `block_on`).
* [`<coasio/time.hpp>`](https://github.com/coasio/coasio/blob/main/include/coasio/time.hpp) — Timers (`timer`), asynchronous sleep (`time::sleep`).
* [`<coasio/net/tcp.hpp>`](https://github.com/coasio/coasio/blob/main/include/coasio/net/tcp.hpp) — TCP sockets, listeners, endpoints, and resolvers.
* [`<coasio/net/udp.hpp>`](https://github.com/coasio/coasio/blob/main/include/coasio/net/udp.hpp) — UDP datagram sockets and endpoints.
* [`<coasio/filesystem.hpp>`](https://github.com/coasio/coasio/blob/main/include/coasio/filesystem.hpp) & [`<coasio/filesystem/file.hpp>`](https://github.com/coasio/coasio/blob/main/include/coasio/filesystem/file.hpp) — Asynchronous filesystem path functions, stream files (`file`), and random access files (`random_access_file`).
* [`<coasio/sync/mutex.hpp>`](https://github.com/coasio/coasio/blob/main/include/coasio/sync/mutex.hpp) & [`<coasio/sync/semaphore.hpp>`](https://github.com/coasio/coasio/blob/main/include/coasio/sync/semaphore.hpp) — Asynchronous synchronization primitives.
* [`<coasio/sync/oneshot.hpp>`](https://github.com/coasio/coasio/blob/main/include/coasio/sync/oneshot.hpp) — One-shot channels (`make_oneshot`).
* [`<coasio/combinators.hpp>`](https://github.com/coasio/coasio/blob/main/include/coasio/combinators.hpp) — `select`, `race`, `join`, and `timeout`.
