## 2. Runtime Configuration (`runtime_builder`)

The [`coasio::runtime_builder`](file:///C:/dev/cpp/coasio/include/coasio/runtime.hpp#L395) class configures and instantiates the runtime:

```cpp
#include <coasio.hpp>

coasio::runtime rt = coasio::runtime_builder{}
    .set_worker_count(8)           // Number of coroutine worker threads
    .set_io_worker_count(2)        // Number of dedicated Asio I/O threads
    .set_blocking_pool_size(4)     // Size of the background blocking pool
    .build();
```

### Configuration Options

| Builder Method | Default Value | Description |
| :--- | :--- | :--- |
| `set_worker_count(size_t)` | `std::thread::hardware_concurrency()` (min 1) | The number of OS threads running coroutines via the work-stealing scheduler. |
| `set_io_worker_count(size_t)` | `1` | The number of threads executing Asio's `io_context::run()` for socket and timer events. |
| `set_blocking_pool_size(size_t)` | `1` | The thread pool capacity dedicated to `spawn_blocking` and filesystem operations. |
