The [`coasio::net`](https://github.com/coasio/coasio/blob/main/include/coasio/net/tcp.hpp) module provides asynchronous socket abstractions built on top of standalone Asio.

---

## 1. Overview & Headers

```cpp
#include <coasio/net/tcp.hpp>        // TCP sockets, listeners, endpoints, resolvers
#include <coasio/net/udp.hpp>        // UDP sockets, endpoints, resolvers
#include <coasio/net/ip_address.hpp> // IP address representation
```

---

## 2. TCP Networking

### `coasio::net::tcp::listener`

Represents a listening TCP acceptor socket.

| Method | Return Type | Description |
| :--- | :--- | :--- |
| `create()` | `listener` | Creates an unbound acceptor associated with the current runtime's I/O context. |
| `bind(endpoint ep, bool reuse_address = true)` | `std::expected<listener, std::error_code>` | Creates, opens, configures `SO_REUSEADDR`, and binds the socket. |
| `listen(int backlog = max)` | `std::expected<void, std::error_code>` | Starts listening for incoming TCP connection requests. |
| `accept()` | `listen_awaiter` $\rightarrow$ `std::expected<tcp::socket, std::error_code>` | Asynchronously accepts a new TCP connection. Supports cancellation. |
| `wait(wait_type)` | `async_op<void>` | Asynchronously waits for read/write/error readiness. |
| `close()` | `std::expected<void, std::error_code>` | Closes the acceptor socket. |
| `is_open()` | `bool` | Returns `true` if the acceptor socket is currently open. |
| `local_endpoint()` | `std::expected<endpoint, std::error_code>` | Returns the local endpoint the listener is bound to. |
| `native_handle()` | `auto` | Accesses the native underlying OS socket handle. |
| `asio_handle()` | `asio::ip::tcp::acceptor&` | Accesses the underlying Asio acceptor. |

### `coasio::net::tcp::socket`

Represents a connected or un-connected TCP stream socket.

| Method | Return Type | Description |
| :--- | :--- | :--- |
| `create()` | `tcp::socket` | Creates a socket bound to the current runtime's I/O context. |
| `connect_to(std::string_view host_and_port)` | `task<std::expected<socket, std::error_code>>` | Resolves a string formatted as `"host:port"` and connects asynchronously. |
| `connect(const endpoint &ep)` | `async_op<void>` | Connects asynchronously to a resolved endpoint. |
| `bind(const endpoint &ep)` | `std::expected<void, std::error_code>` | Binds the socket to a local endpoint. |
| `read(buffer)` | `async_op<size_t>` | Asynchronously reads until `buffer` is completely filled or EOF/error occurs. |
| `read_some(buffer)` | `async_op<size_t>` | Asynchronously reads at least 1 byte (up to buffer capacity). |
| `write(buffer)` | `async_op<size_t>` | Asynchronously writes all bytes from `buffer`. |
| `write_some(buffer)` | `async_op<size_t>` | Asynchronously writes as many bytes as can be sent immediately. |
| `available()` | `std::expected<size_t, std::error_code>` | Returns the number of bytes available to read immediately without blocking. |
| `shutdown(shutdown_type)` | `std::expected<void, std::error_code>` | Shuts down `shutdown_receive`, `shutdown_send`, or `shutdown_both`. |
| `close()` | `std::expected<void, std::error_code>` | Closes the socket. |
| `is_open()` | `bool` | Returns `true` if the socket is currently open. |
| `remote_endpoint()` | `std::expected<endpoint, std::error_code>` | Returns the remote peer endpoint. |
| `local_endpoint()` | `std::expected<endpoint, std::error_code>` | Returns the local endpoint. |
| `native_handle()` | `auto` | Accesses the native underlying OS socket handle. |
| `asio_handle()` | `asio::ip::tcp::socket&` | Accesses the underlying Asio socket object. |

## 3. UDP Networking

### `coasio::net::udp::socket`

Represents an asynchronous UDP datagram socket.

| Method | Return Type | Description |
| :--- | :--- | :--- |
| `create()` | `udp::socket` | Creates a UDP socket bound to the current runtime's I/O context. |
| `bind(const endpoint &ep)` | `std::expected<void, std::error_code>` | Binds the socket to a local UDP port/address. |
| `connect(const endpoint &ep)` | `async_op<void>` | Establishes a default remote target endpoint. |
| `connect_to(std::string_view host_and_port)` | `task<std::expected<socket, std::error_code>>` | Resolves and connects to a target host and port. |
| `receive(buffer, flags = {})` | `async_op<size_t>` | Receives a datagram from a connected peer. |
| `receive_from(buffer, endpoint &sender)` | `async_op<size_t>` | Receives a datagram and captures the sender endpoint. |
| `send(buffer, flags = {})` | `async_op<size_t>` | Sends a datagram to a connected peer. |
| `send_to(buffer, const endpoint &target)` | `async_op<size_t>` | Sends a datagram to a specific remote endpoint. |
| `wait(wait_type)` | `async_op<void>` | Asynchronously waits for read/write/error readiness. |
| `available()` | `std::expected<size_t, std::error_code>` | Returns the number of bytes available to read immediately without blocking. |
| `shutdown(shutdown_type)` | `std::expected<void, std::error_code>` | Shuts down `shutdown_receive`, `shutdown_send`, or `shutdown_both`. |
| `close()` | `std::expected<void, std::error_code>` | Closes the UDP socket. |
| `is_open()` | `bool` | Returns `true` if the UDP socket is currently open. |
| `remote_endpoint()` | `std::expected<endpoint, std::error_code>` | Returns the remote peer endpoint. |
| `local_endpoint()` | `std::expected<endpoint, std::error_code>` | Returns the local endpoint. |
| `native_handle()` | `auto` | Accesses the native underlying OS socket handle. |
| `asio_handle()` | `asio::ip::udp::socket&` | Accesses the underlying Asio socket. |

## 4. IP Addresses & Resolvers

### `coasio::net::ip_address`

Represents an IPv4 or IPv6 address wrapping `asio::ip::address`.

* `ip_address::v4()`: Returns `0.0.0.0` (`address_v4::any()`).
* `ip_address::v6()`: Returns `::` (`address_v6::any()`).
* `ip_address::v4(uint32_t addr)`: Creates an IPv4 address from host byte order integer.
* `ip_address::v6(std::array<uint8_t, 16> addr)`: Creates an IPv6 address from byte array.
* `ip_address::from_string(std::string_view ip)`: Parses an IP string into `std::expected<ip_address, std::error_code>`. Example: `from_string("127.0.0.1")` or `from_string("::1")`.
* `is_v4()`, `is_v6()`, `is_loopback()`, `is_multicast()`, `is_unspecified()`: Inspection queries.
* `to_string()`: Returns human-readable string representation.
* `asio_address()`: Direct access to underlying `asio::ip::address`.

### Resolvers

* `coasio::net::tcp::resolver::create()` / `udp::resolver::create()`:
  * `co_await resolver.resolve(host, service_or_port)`: Asynchronously resolves DNS names into endpoint lists.

## 5. Buffer Compatibility

Coasio networking methods are templated to accept any contiguous range whose elements satisfy `coasio::detail::byte_like`:

* `std::span<std::byte>` or `std::span<char>`
* `std::vector<char>`, `std::vector<std::byte>`, `std::vector<uint8_t>`
* `std::string` or `std::string_view` (for write operations)
* Raw arrays (`char buf[1024]`)

```cpp
std::vector<char> buf(512);
auto n = co_await sock.read_some(buf); // Perfectly valid
```
