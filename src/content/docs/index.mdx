We love Asio. It's the battle-tested backbone of high-performance C++ networking. But writing asynchronous code with raw completion handlers and callbacks in 2026 feels like writing assembly when modern language coroutines exist.

**CoAsio** bridges the gap. It keeps Asio where it shines—multiplexing I/O and driving timers—while providing a separate, dedicated scheduler for coroutines.

---

### What it looks like in practice

Write sequential-looking code that executes asynchronously without blocking the event loop:

```cpp title="echo_server.cpp"
#include <coasio.hpp>
#include <coasio/net/tcp.hpp>
#include <iostream>
#include <vector>

coasio::task<void> handle_client(coasio::net::tcp::socket socket) {
    std::vector<std::byte> buffer(1024);
    while (true) {
        auto read_res = co_await socket.read_some(buffer);
        if (!read_res || *read_res == 0) break; // Disconnected or error
        
        auto write_res = co_await socket.write({buffer.data(), *read_res});
        if (!write_res) break;
    }
}

coasio::task<void> start_server(uint16_t port) {
    auto maybe_listener = coasio::net::tcp::listener::bind(
        coasio::net::tcp::endpoint{coasio::net::ip_address::v4(), port}
    );
    if (!maybe_listener) co_return;

    auto listener = std::move(*maybe_listener);
    if (!listener.listen()) co_return;

    std::cout << "Listening on port " << port << "...\n";

    while (true) {
        auto maybe_socket = co_await listener.accept();
        if (!maybe_socket) break;

        coasio::spawn(handle_client(std::move(*maybe_socket)));
    }
}
```

### Built for predictability, not buzzwords.

<CardGrid>
  <Card title="No Hidden Magic" icon="puzzle">
    Pure C++23 `co_await` and `task<T>`. Clean standard types, explicit cancellation scopes, and structured task lifecycles.
  </Card>

  <Card title="Dual-Engine Architecture" icon="workflow">
    Asio runs the I/O event demultiplexer (epoll/kqueue/IOCP). A dedicated thread pool runs your coroutines. Network polling never starves compute, and compute never starves I/O.
  </Card>

  <Card title="Structured Lifetimes" icon="shield">
    Child tasks do not outlive parent scopes by surprise. Cancellation propagates cooperatively down the task tree so sockets and resources close cleanly.
  </Card>

  <Card title="Standalone Asio Backend" icon="network">
    CoAsio is built directly on standalone Asio (1.38+) for OS-native multiplexing without imposing external dependencies or heavy macro abstractions.
  </Card>
</CardGrid>
